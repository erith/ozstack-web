오즈스택 OZSTACK AX Foundation

오즈스택은 AX를 기반으로 아이디어를 시스템으로, 업무를 인사이트로 연결하며, 개선이 다음 기회로 이어지도록 합니다. MES·MSA 플랫폼, 데이터 API 및 반도체 시각화 API를 개발하고 운영합니다.

We use AX as the basis for how ideas become systems, how work becomes insight, and how each improvement creates the next opportunity. We develop and operate MES/MSA platforms, data APIs and semiconductor visualization APIs.
